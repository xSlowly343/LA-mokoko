# Тропа мококо

Краткий гайд по системам развития Lost Ark (русская версия) для новичков, плюс новости, события и промокоды.

## Что внутри

- **Главная — краткий гайд по системам развития**: обложка, «Зачем я здесь?» и вкладки «Снаряжение», «Система АРК», «Гравировки», «Самоцветы», «Колоды», «Созвездия АРК». На скриншотах есть кликабельные области — по нажатию справа появляется пояснение, а ниже дополнительная информация. Контент лежит в `js/guide-data.js`, картинки в `assets/guide/`.
- **Новости** — свежие новости с lostark.ru, обновляются сами каждый час; недавние помечены NEW.
- **События** — что идёт в игре прямо сейчас, сколько осталось и какие награды.
- **Промокоды** — официальные коды и быстрая активация.

Запуск локально: `python3 -m http.server` в корне репозитория. После правок JS/CSS — `python scripts/bump_version.py`.

## Принцип

Каждый факт взят из официальных источников русской версии (lostark.ru) и подписан датой. Нет источника — нет факта.
