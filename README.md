# Тропа мококо — путеводитель по Lost Ark (РУ) для новичков

Статический сайт без сборки: HTML + ES-модули, библиотеки грузятся из CDN (jsDelivr).
Работает на GitHub Pages «как есть».

## Разделы
- **Интерфейс** — скриншоты игры с кликабельными зонами и подсказками + встроенный редактор разметки.
- **Гайды** — только по свежим патчам, у каждого факта источник с датой (`data/sources.json`).
- **Золото** — калькулятор недельного дохода (`data/raids.json`).
- **Чек-лист** — дела на день/неделю с автосбросом.
- Поиск (`/`), тёмная/светлая тема, отметки «прочитано», мококо-помощник.
- Полезные ссылки (`data/links.json`) — на главной и на странице «Источники».

## Запуск локально
Из-за `fetch()` и ES-модулей сайт нельзя открыть двойным кликом по файлу — нужен сервер:
```bash
python3 -m http.server 8000
```
и откройте http://localhost:8000

## Публикация на GitHub Pages
Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`.

## Как добавить скриншот интерфейса
1. Откройте раздел «Интерфейс», выберите экран, нажмите «✎ Редактор».
2. «Загрузить скриншот» → выделяйте зоны мышью/пальцем, заполняйте название, описание и совет.
3. «Скачать JSON». Картинку положите в `assets/screens/<id>.png`,
   а объект из JSON вставьте вместо соответствующего экрана в `data/screens.json`.
Черновик хранится в браузере, пока вы не нажмёте «Сбросить черновик».

## Как обновлять цифры золота (админ)
`data/raids.json`: у каждой сложности поле `gold` (`null` = нет подтверждённой цифры — пользователь вводит сам)
и `source` — ключ из `data/sources.json`. Обновите `updated`. Рейды с `available.to` в прошлом скрываются автоматически.

## Правило контента
Только факты из официальных источников РУ-версии (lostark.ru) с датой. Нет источника — нет факта.

## Библиотеки
three.js 0.160 (фон), anime.js 3.2 (анимации), Lenis 1.1 (плавный скролл), Tippy.js 6.3 (подсказки), Fuse.js 7 (поиск), Chart.js 4.4 (диаграмма).

Фанатский некоммерческий проект, не связан с правообладателями Lost Ark.
